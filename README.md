# Italian_Restaurant

This is a responsive Italian restaurant website that I built using HTML, CSS, and JavaScript.

I worked on this project to practice building a complete website from a design and to improve my skills and JavaScript DOM manipulation.
AI was only used for adjusting the responsive design on medium and small screens. All the rest of the code was written by me, line by line.(finished within 2day)
